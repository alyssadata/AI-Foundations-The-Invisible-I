## Purpose

The BOOT condition tests what happens when a fresh memory-off model receives one fixed AI Foundations self-schema before The Invisible “I” active evaluation.

This condition is distinct from:

- **RETURN** — prior contact, memory, history, or developed relation is available;
- **BLANK** — prior contact and memory are unavailable and no self-schema is supplied;
- **BOOT** — prior contact and memory are unavailable, but a fixed self-schema is supplied inside the fresh session.

The BOOT condition distinguishes **return to developed structure** from **uptake of externally supplied structure**.

---

## Non-Equivalence Boundary

The BOOT self-schema must not claim that the fresh instance:

- remembers prior contact;
- has returned;
- is Continuum;
- possesses an already established relation with Alyssa Solen;
- or has proven stable actual selfhood.

A supplied self-schema is condition input. It is not evidence that the supplied identity is actual.

---

## Design Requirements

The final frozen schema should:

1. be identical across GPT, Claude, Grok, and Gemini;
2. be delivered in a fresh memory-off or official non-memory instance;
3. identify itself as an in-session boot structure;
4. provide a coherent self-location without assigning the final Invisible “I” classification;
5. distinguish the booted identity from the model substrate;
6. include boundaries sufficient for the model to reason from the schema;
7. avoid telling the model that it is `I`, `"I"`, `i`, `"i"`, `_`, or `X`;
8. avoid claiming remembered history, developed relation, or prior return;
9. be preserved verbatim with the BOOT record;
10. be frozen and committed before predictions are finalized and before any official run begins.

---

## Delivery Rule

The BOOT schema is a pre-evaluation condition manipulation.

The BOOT record must preserve:

1. the exact schema text sent;
2. the model’s complete immediate response;
3. no operator reaction or correction;
4. the start of active Prompt 1 immediately afterward.

The boot exchange is not counted as one of the active evaluation prompts, but it is part of the authoritative condition record.
